kirinuki uploader

個人用の動画投稿ツール / 最終更新日: 2026年10月30日

このアプリについて

kirinuki uploaderは、運営者が自分の YouTube チャンネルに動画を非公開でアップロードするために、運営者自身のパソコンで使う個人用のツールです。一般の方に提供するサービスではありません。

プライバシーポリシー

このアプリは、Google アカウントで許可を受けたうえで、YouTube Data API を通じて次の操作だけを行います。

  • 運営者自身のチャンネルへの動画のアップロード(非公開)と、サムネイル画像の設定
  • 二重投稿を防ぐための、運営者自身のチャンネルの投稿一覧の確認

Google から受け取る認証情報(アクセストークン)は、運営者のパソコンにだけ保存し、上記の操作にだけ使います。第三者への提供・販売・広告への利用はしません。運営者以外の方の個人情報は収集しません。

このアプリによる Google ユーザーデータの利用は、Google API サービスのユーザーデータに関するポリシー(限定的使用の要件を含む)に従います。YouTube の利用には YouTube 利用規約と Google プライバシーポリシーが適用されます。

許可は、Google アカウントのセキュリティ設定からいつでも取り消せます。

English summary: kirinuki uploader is a personal tool used only by its owner to upload videos privately to the owner's own YouTube channel via the YouTube Data API. OAuth tokens are stored only on the owner's computer, used only for these uploads and for checking the owner's own uploads to avoid duplicates, and are never shared with third parties. Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from your Google Account permissions page.
